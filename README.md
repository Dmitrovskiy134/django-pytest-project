# Django Project with Pytest Tests

## Описание проекта
Проект представляет собой Django REST API для управления курсами и студентами. 
В проекте реализованы тесты с использованием pytest.

## Технологии
- Python 3.11
- Django 5.2
- Django REST Framework
- Pytest
- Model Bakery
- Django Filter
